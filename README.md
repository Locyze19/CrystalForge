# Crystal Forge — Telegram Mini App

Idle/кликер с 3D-кристаллом, шахтёрами, ежедневными наградами, рефералами, рейтингом и покупками за Telegram Stars.

## Требования
- Node.js 18+
- Домен с HTTPS (Telegram открывает Mini App только по HTTPS)

## Быстрый старт
1. В @BotFather: `/newbot` → получите токен.
2. `/newapp` → выберите бота, укажите URL вашего сервера и короткое имя (например `play`).
3. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен бота
   - `BOT_USERNAME` — имя бота без @
   - `APP_SHORT_NAME` — короткое имя Mini App из шага 2
   - `WEBAPP_URL` — публичный HTTPS-адрес сервера
   - `ADMIN_ID` — ваш Telegram ID для команды /stats
4. `npm start`

При запуске сервер сам ставит webhook, кнопку меню «Играть» и команды бота.

## Локальный тест в браузере
```
DEV=1 npm start
```
Откройте http://localhost:3000 — покупки в DEV-режиме выдаются бесплатно.

Для теста внутри Telegram используйте туннель (ngrok, cloudflared) и укажите его адрес в `WEBAPP_URL` и в BotFather.

## Арена (асинхронное PvP)
Во вкладке «Гильдия» игроки сражаются со слепками друг друга: бой считается на сервере, защитник получает запись в журнал и уведомление от бота. Рейтинг Эло, 5 лиг, билеты (5 штук, +1 каждые 2 часа), реванш, сундук лиги. Если живых соперников мало, подбираются Тени — боты под силу игрока, поэтому арену можно проверить и в DEV-режиме.

## Экспедиции и башня (PvE)

Экспедиции на 1, 3 и 6 часов приносят кристаллы, жетоны и предметы; когда отряд возвращается, бот присылает сообщение. Бесконечная башня: каждый этаж сильнее предыдущего, каждые 5 этажей босс, каждые 25 — титан, 5 попыток в день тратятся только на поражения.

## Деплой
Подойдёт любой VPS, Render, Railway, Fly.io. Важно: папка `data/` хранит базу игроков — используйте постоянный диск.

## Telegram Stars
Валюта `XTR`, provider token не нужен. Выручку можно вывести через Fragment в разделе бота @BotFather → Payments / Stars Balance. Команда `/paysupport` обязательна по правилам Telegram и уже реализована.

## Структура
- `public/` — клиент (index.html, style.css, engine.js — 3D-движок, app.js — логика)
- `server/server.js` — API, бот, платежи, рейтинг
- `data/db.json` — база (создаётся автоматически)
- `log.txt` — что сделано и что осталось

## CRM и админ-панель

Отправьте боту /admin и нажмите «Открыть CRM-панель». Доступ есть только у владельца (ADMIN_ID) и назначенных админов. Права админа может выдавать только владелец.

Разделы: Обзор, Игроки, Платежи, Рассылка, Игра, Журнал.
